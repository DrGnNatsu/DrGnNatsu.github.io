## Problem

PostgreSQL ships with conservative default configuration values designed to boot reliably on minimal hardware. Tuning `postgresql.conf` manually for production workloads requires deep knowledge of memory allocation, WAL behavior, query planner cost constants, and iterative benchmarking—time most engineering teams do not have during initial setup.

## Solution

PGTuner is a client-side web tool that analyzes hardware specs and workload characteristics (total RAM, CPU cores, storage medium, connection count, and workload profile such as OLTP, OLAP, or mixed) to compute an optimized `postgresql.conf` tailored to your environment.

## Architecture

- **Frontend:** Astro + TypeScript + Tailwind CSS compiled to static assets on GitHub Pages.
- **Tuning Engine:** Pure client-side calculation—zero backend dependencies, and no infrastructure metadata ever leaves your browser.
- **Output:** Ready-to-copy `postgresql.conf` blocks paired with parameter-by-parameter rationale.
