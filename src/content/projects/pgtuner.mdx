# PGTuner — PostgreSQL Configuration Tuner

## Problem

PostgreSQL ships with conservative default configuration values designed to work on any hardware. Tuning `postgresql.conf` manually requires deep expertise and iterative benchmarking — time most engineering teams don't have.

## Solution

PGTuner is a client-side web tool that analyzes your workload characteristics (database size, connection count, storage type, OLTP vs OLAP) and generates an optimized `postgresql.conf` tailored to your environment.

## Architecture

- **Frontend:** Astro + TypeScript + Tailwind CSS (static, GitHub Pages)
- **Logic:** Pure client-side calculation — no server, no data leaves your browser
- **Output:** Ready-to-paste `postgresql.conf` settings with explanations
