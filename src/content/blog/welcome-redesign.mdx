# Welcome to the Redesign

This site has been rebuilt from scratch with **Astro**, **Tailwind CSS**, and **TypeScript** — static output hosted on GitHub Pages.

## Focus

The site serves three goals:

1. **Engineering career & recruiter portfolio** — flagship full-stack and AI/ML work, technical depth, timeline, and resume access.
2. **Active technical blog** — engineering notes, architecture deep-dives, and AI/ML learnings in Markdown/MDX.
3. **Freelance & consulting showcase** — service offerings, engagement workflow, and an inquiry path for clients.

## Tech Stack

- Astro (static, GitHub Pages)
- Tailwind CSS (design tokens, light/dark theming)
- TypeScript (strict)
- Astro Content Collections (MDX)

Stay tuned for deep-dives on LLM integration, RAG pipelines, fine-tuning, and MLOps.
