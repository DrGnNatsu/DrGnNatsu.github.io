This site has been rebuilt from scratch with **Astro**, **Tailwind CSS**, and **TypeScript**—compiled to static output and hosted on GitHub Pages.

## Goals Behind the Rebuild

The site is structured around three complementary purposes:

1. **Engineering career & recruiter portfolio** — Highlight flagship full-stack and AI/ML systems, technical depth, timeline, and resume access.
2. **Active technical blog** — Publish architecture deep-dives, LLM engineering notes, and performance findings in Markdown and MDX.
3. **Freelance & consulting showcase** — Present clear service offerings, engagement workflow, and a zero-friction inquiry path.

## Architecture Snapshot

Content collections are validated at build time via Astro's Content Layer API, keeping markdown entries strictly typed without runtime overhead:

```ts
import { defineCollection } from 'astro:content'
import { glob } from 'astro/loaders'
import { z } from 'astro/zod'

export const blog = defineCollection({
  loader: glob({ pattern: '**/[^_]*.{md,mdx}', base: './src/content/blog' }),
  schema: z.object({
    title: z.string(),
    description: z.string(),
    tags: z.array(z.string()).default([]),
    published: z.boolean().default(true),
    date: z.date(),
  }),
})
```
